# 发布检查表

## 内容

- [ ] 首帧/标题清楚说明地点与价值
- [ ] 地名、人名、数字、距离、时长无误
- [ ] 文案、字幕、封面无错别字
- [ ] 平台规格、定位、话题和 CTA 正确
- [ ] 不含不安全示范、违规穿越或误导性画面

## 动态信息

- [ ] 开放、票务、交通、天气等信息已由对应负责人核验
- [ ] 核验时间已记录
- [ ] 官方链接和客服电话可用
- [ ] 必要时注明“以景区当日官方信息为准”

## 权利与合规

- [ ] 人像、游客作品和第三方素材已获授权
- [ ] 音乐、字体、图片具有可用授权
- [ ] 广告、合作、抽奖等内容已按适用规则审核
- [ ] AI 生成或合成内容已按规则清晰标识

## 发布后

- [ ] Issue 状态更新为 `published`
- [ ] 发布链接与截图归档
- [ ] 安排首 2 小时互动值守
- [ ] 安排 24 小时和 7 天数据记录
