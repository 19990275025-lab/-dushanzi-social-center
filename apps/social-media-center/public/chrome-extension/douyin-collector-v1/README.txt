独山子新媒体中心 · 抖音 Chrome 采集器 V1.2

安装：
1. 解压下载包。
2. Chrome 打开 chrome://extensions。
3. 开启“开发者模式”，点击“加载已解压的扩展程序”。
4. 选择 douyin-collector-v1 文件夹。

使用：
1. 登录自己有权管理的抖音创作者账号。
2. 打开作品管理列表，筛选近 30 天并加载需要采集的作品。
3. 点击扩展图标，选择“采集近 30 天作品”。
4. 导出标准 JSON。
5. 在新媒体智能采集中心上传，校验并人工确认后写入 social_posts。

评论采集：
1. 在作品管理列表点击作品的评论数量，进入评论详情。
2. 加载需要采集的评论，点击扩展的“采集当前作品评论”；支持创作者中心评论详情页。
3. 每个作品最多读取前 50 条评论，导出评论标准 JSON。
4. 在智能采集中心预览并人工确认后写入 social_comments。

安全边界：
- 扩展仅读取当前页面已显示的作品卡片或评论。
- 不读取 Cookie、密码或浏览器历史。
- 不绕过登录、验证码、风控或平台限制。
- 不会直接写入数据库；入库前必须在系统内确认。
- 页面结构发生变化时可能需要升级采集适配器。
