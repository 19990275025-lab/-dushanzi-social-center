# 组织与岗位

## 最小可运行团队

| 岗位 | 建议人数 | 核心职责 |
|---|---:|---|
| 运营负责人/主编 | 1 | 目标、排期、审批、跨部门协调、风险升级 |
| 内容策划/文案 | 1–2 | 选题、脚本、图文、平台适配、复盘 |
| 摄影/剪辑 | 1–2 | 拍摄、剪辑、封面、素材归档 |
| 平台运营/社群客服 | 1–2 | 发布、互动、咨询转办、舆情监测 |
| 数据与投放 | 0.5–1 | 数据看板、归因、A/B 测试、预算优化 |

初期可一人多岗，但审核人不能与内容提交人完全重合；安全、票务、开放等信息必须由业务岗位承担最终事实责任。

## RACI

R=执行，A=最终负责，C=协商，I=知会。

| 事项 | 运营负责人 | 内容团队 | 业务负责人 | 安全负责人 | 客服 | 管理负责人 |
|---|---|---|---|---|---|---|
| 常规内容 | A | R | C | I | I | I |
| 票务/开放信息 | C | R | A | I | C | I |
| 安全内容 | C | R | C | A | I | I |
| 普通投诉 | I | C | C | I | A/R | I |
| P0/P1 舆情 | R | C | C | C | C | A |
| 月度经营复盘 | A/R | C | C | C | C | I |

## 值班交接

交接记录至少包含：当日发布、待回复评论、未结咨询、开放信息变化、风险事件、次日拍摄和待审核内容。旺季、节假日和极端天气期间必须明确到人到时段。
