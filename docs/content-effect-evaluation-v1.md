# 抖音内容效果评价模型 V1.0

## 1. 定位

本模型只评价已写入新媒体运营中心的真实抖音作品数据，用于回答“作品表现如何、为什么好/差、是否依赖 DOU+、下一条如何优化”。它是可解释的规则模型，不调用外部大模型，不生成模拟业务数据。

## 2. 评分结构

| 维度 | 满分 | 主要真实证据 |
| --- | ---: | --- |
| 内容传播力 | 30 | 账号内播放分位、发布至快照的播放速度、真实趋势点、推荐/搜索流量、分享率 |
| 互动质量 | 25 | 点赞率、评论率、收藏率、分享率、最新快照真实评论质量、平台评论热词 |
| 用户吸引力 | 25 | 作品涨粉、页面进入、关注页流量、作品级观众与目标游客的匹配、真实评论反馈 |
| 内容效率 | 20 | 视频使用完播、播放进度、平均观看时长、2秒跳出、5秒完播和真实留存点；图文改用文字读完/展开、平均浏览图片和收藏/评论效率 |

互动率只在播放和互动计数都有明确口径时计算。完整缺失的指标不记 0 分：维度内按可用指标重新加权，缺失整个维度时显示“暂无评分”，综合分只按其他可用维度重新加权，同时降低数据完整度和等级上限。

## 3. 账号动态基准

评分优先使用独山子大峡谷抖音账号已入库的真实历史作品，计算最近 7 天、最近 30 天、历史播放中位数、TOP25% 和 TOP10% 门槛。不使用一组固定行业绝对阈值评判所有作品。

当自身历史播放样本少于 10 或拥有详细流量/观众/趋势的样本少于 10 时，系统明确显示：“历史样本不足，当前评分为初步评价。”

## 4. DOU+ 保护

- DOU+ 在 `social_post_paid_traffic` 中独立读取，页面标记“含付费流量”。
- 当平台明确记录 DOU+ 为 `additional` 时，基础播放可作为独立的自然口径证据。
- 当关系为 `included` 或 `unknown` 时，自然播放保持 `null`，可信度为 `low`；系统不执行“总播放 - DOU+ 播放”推算。
- 任何含 DOU+ 的作品都不能被判为“自然爆款”；播放达到自身历史 TOP25% 时可标记“投流放大型高播放作品”。

## 5. 等级与独立标签

| 等级 | 含义 |
| --- | --- |
| S | 自然爆款；必须同时具有充分自然传播证据、无 DOU+ 且达到账号历史 TOP10% |
| A | 优秀内容 |
| B | 正常内容 |
| C | 需要优化 |
| D | 低效内容 |

独立标签包括：含付费流量、数据不足、私密作品、平台数据过期、自然爆款、投流放大型高播放作品。私密作品不计算综合分，不参与正常排名。

本次仅使用 WorkBuddy 深度作品 V2.1 已入库数据，不使用模拟数据。当前深度批次含 3 条公开作品和 1 条私密作品；私密作品已排除。

## 7. 页面与接口

- `GET /api/content-monitoring`：返回作品综合分、四维分、等级、标签、数据完整度和排行榜汇总。
- `GET /api/insights/content/detail?id=<post_id>`：返回单作品的动态基准和八项证据化诊断。
- `/insights/content?platform=douyin`：默认按综合效果排序，可切换自然传播、互动质量、完播表现、涨粉能力和 DOU+ 作品。
- `/insights/content/detail?id=<post_id>`：默认打开“效果评价”，显示得分理由、真实指标和下一条优化建议。

本模型不新增数据库表，不修改 WorkBuddy 和任何采集逻辑。
