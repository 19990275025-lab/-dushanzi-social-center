# 运营中心章程

## 使命

用真实、可信、有冲击力的内容，让用户在出发前理解独山子大峡谷的独特体验、合理规划行程，并在到访过程中获得清晰、安全、友好的服务信息。

## 业务目标

- 品牌：形成稳定、可识别的目的地形象。
- 增长：持续获得目标游客的有效触达和收藏意向。
- 转化：把内容兴趣导向地图搜索、咨询、预约/购票及实际到访。
- 服务：降低高频信息差，提升游客决策效率与满意度。
- 风险：确保安全、票务、开放状态等信息准确并可快速纠错。

## 工作原则

1. **真实优先**：不夸大景观、项目和服务，不制造虚假稀缺。
2. **安全优先**：危险机位、违规穿越和误导性示范不得用于传播。
3. **用户有用**：每条内容至少解决“为什么来、怎么来、怎么玩、是否适合”中的一个问题。
4. **平台原生**：同一主题按平台重新组织，不做机械搬运。
5. **数据闭环**：没有复盘的内容不算完成。
6. **单一事实源**：动态业务信息以景区指定负责人确认结果为准。

## 决策边界

| 事项 | 最终负责人 | 发布前置条件 |
|---|---|---|
| 品牌内容 | 运营负责人 | 内容审核通过 |
| 开放、票务、交通 | 景区业务负责人 | 当日/当期信息复核 |
| 安全提示、项目规则 | 安全负责人 | 风险表述与现场规则复核 |
| 投诉回复 | 客服负责人 | 事实核查及处理方案 |
| 媒体声明、重大舆情 | 管理负责人 | 统一口径批准 |

## 固定工作节奏

- 每日 09:30：15 分钟站会，确认天气、开放状态、热点和当日发布。
- 每日 17:30：互动与风险回看，补充高频问题。
- 每周一：选题会，锁定未来 14 天内容。
- 每周五：数据复盘，决定放大、优化或停止的内容类型。
- 每月：经营复盘，评估品牌、增长、转化、服务和风险五类指标。

## 90 天里程碑

| 阶段 | 时间 | 交付结果 |
|---|---|---|
| 建制 | 第 1–2 周 | 账号权限、品牌口径、素材库、审批链路就绪 |
| 冷启动 | 第 3–4 周 | 完成首月内容发布，获得各平台基线数据 |
| 验证 | 第 2 月 | 找到 2–3 个稳定内容栏目与主要转化路径 |
| 放大 | 第 3 月 | 复制高效栏目，启动达人/媒体合作与季度主题策划 |
