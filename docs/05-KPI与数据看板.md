# KPI 与数据看板

## 北极星指标

**可归因的有效到访意向数**：通过官方内容产生并能追踪到的预约/购票、有效咨询、地图导航或指定活动报名。

如果暂时无法打通交易数据，先用“高意向行为数”作为代理指标，并在报表中标明不是实际到访。

## 指标分层

| 层级 | 指标 | 定义 |
|---|---|---|
| 品牌 | 有效触达 | 平台口径下的去重触达或可比曝光 |
| 内容 | 完播率/读完率 | 完整消费内容的人数 ÷ 开始消费人数 |
| 兴趣 | 深度互动率 | 收藏 + 分享 + 有效评论 ÷ 曝光 |
| 意向 | 高意向行为 | 主页访问、地点搜索、链接点击、有效咨询 |
| 转化 | 可归因转化 | 带参数链接、专属码或客服标签识别的预约/购票/报名 |
| 服务 | 首次响应时长 | 用户提问至首次有效回复的时间 |
| 风险 | 信息差错率 | 经确认的事实错误内容数 ÷ 发布内容数 |

## 冷启动目标设定

前 30 天不建议凭空写死绝对目标。先完成基线测量：

1. 按平台记录所有内容的中位数，不用平均数掩盖波动。
2. 第 2 月目标可设为：核心指标较首月中位数提升 15%–25%。
3. 转化目标必须基于可追踪链路，无法归因的数据单独列示。
4. 安全和事实准确属于守门指标，不能用增长结果抵消。

## 周报最小字段

- 发布数、有效触达、观看/阅读完成度
- 收藏、分享、有效评论及深度互动率
- 主页访问、链接点击、有效咨询、可归因转化
- 表现最佳/最差内容及原因假设
- 用户高频问题、负面反馈和风险事项
- 下周继续、停止、测试的各一项动作

## 决策规则

- 连续 3 条同类内容显著高于平台中位数：进入栏目化验证。
- 有触达无收藏/咨询：优化信息价值和 CTA。
- 收藏高但转化低：检查信息完整度、链接路径与产品承接。
- 互动高但负面集中：先做定性核查，不直接视为成功。
- 发现事实或安全错误：立即纠错，数据表现不影响处置。
